# 角色试用和映射配置

适用于4.7正式版的货币战争 S2。试用表覆盖 61 个角色，映射表覆盖 60 个常规角色。星神★阿哈的三个玩法形态共用一行。

角色自身的属性见[角色 ID 与 80 级基础数值](character-data.md)，局内星级属性见[货币战争角色数值](currency-wars-character-data.md)。

- 有强化形态的角色在货币战争中固定使用强化形态。
- 试用光锥和默认映射光锥的叠影均为 1。
- 行迹基础等级按普攻、战技、终结技、天赋的顺序列出，特殊技能的基础等级另列。星魂附加的技能等级由星魂计算。小行迹列列出未激活的属性节点。
- 遗器属性合计包含主属性和副属性。固定值和百分比各自列出，套装效果按套装 ID 另行计算。数值最多保留四位小数。
- `—` 表示没有对应条目。
