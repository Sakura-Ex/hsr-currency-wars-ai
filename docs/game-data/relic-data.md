# 五星遗器数据

适用范围：五星、强化等级 +15。本文用于查看生成参数、解释生成结果和对接配置转换。主词条已按成长数据核对，副词条沿用已确认数值；当前生成接口见[单件遗器生成与评分](../modules/account-generation/relic-generation.md)。

## 字段与单位

| 字段 | 含义 |
| --- | --- |
| `set_id` | 套装 ID，使用字符串，例如 `"115"` |
| `slot` | 整数部位 ID，取值 1～6，见下表 |
| `mainstat` | 主词条属性键，与副词条使用相同含义 |
| `substats` | 属性键到最终数值的字典，例如 `{"SPD": 6.9, "HP_": 0.077760004}` |

文档数值表中的百分比属性使用百分比展示，例如 `3.24%`、`43.2%`；代码和代码示例使用对应比例值 `0.0324`、`0.432`。换算关系为“程序比例值 = 百分数 ÷ 100”。固定生命、固定攻击、固定防御和速度保持原值。

当前生成结果保存主词条键；主词条最终数值供配置转换按部位与属性查询。

### 主副词条关系

一件遗器的四种副词条互异，并排除与主词条完全相同的属性：

- 固定生命主词条排除固定生命副词条，允许生命%。
- 生命%主词条排除生命%副词条，允许固定生命。
- 固定攻击与攻击%按相同方式分别处理。
- 防御%、速度、暴击率、暴击伤害、效果命中和击破特攻主词条，分别排除对应副词条。

### +15 成品与有效词条

初始三词条∶四词条的基础抽样概率为 **5∶2**，分别为 `5/7` 和 `2/7`。目标生成以此抽取优先候选，再按有效词条要求筛选成品；高分目标会提高四词条起始成品的占比。

初始三词条遗器的第一次强化新增第四条，后续四次强化提升已有词条，共获得八次数值。初始四词条遗器强化五次，共获得九次数值。每条副词条最终数值等于其各次档位数值之和。

中档记作一条有效词条，再按调用方提供的角色权重折算：

```text
有效词条 = Σ(角色权重 × 副词条最终数值 ÷ 该属性单次中档数值)
```

账号生成按推荐副词条原始顺序采用 `1 / 1 / 0.5 / 0.3` 的权重，第 4 项及以后沿用 `0.3`，未列出属性计零分。约定与示例见[推荐副词条权重](../modules/account-generation/design.md#推荐副词条权重)。

例如速度由低、中、高档各一次组成，最终数值为 `2.6 + 2.0 + 2.3 = 6.9`。速度权重为 1 时计 `6.9 ÷ 2.3 = 3` 条；权重为 0.5 时计 1.5 条。
