# 角色 ID 与 80 级基础数值

范围：S2 货币战争图鉴名单，共 61 个条目，其中 60 个对齐常规角色档案，玩法专属的帕姆王在末尾单列。按命途分组，章节标题括号内为资料中的命途键。

常规角色数值的游戏内对照待完成。光锥资料见[光锥 ID 与 80 级基础数值](light-cone-data.md)，完整账号字段见[数据设计](../modules/account-generation/design.md)。

## 字段与计算口径

- **角色 ID**：账号配置使用的常规角色 ID，以字符串传递。不同命途形态按各自 ID 区分。
- **中文名**：使用货币战争图鉴中的显示名。
- **能量上限**：常规能量或括号所示专属资源的上限。资源的触发和溢出规则按角色技能处理。玩法角色 ID 见[货币战争角色数值](currency-wars-character-data.md)。
- **稀有度**：常规角色的四／五星稀有度，局内星级由整局配置提供。
- **基础数值**：角色 80 级、突破阶段 6 的自身数值；行迹节点、星魂、光锥、遗器和局内效果由后续转换与组装计算。
- **嘲讽值**：角色在突破阶段 6 的基础嘲讽权重。常规角色已按 ID 核对 4.7 正式版的 `base_aggro` 字段，战斗中的嘲讽修正另计。

生命、攻击、防御按以下公式计算，并保留小数精度；速度直接读取基础值。

```text
80 级基础值 = 突破阶段 6 的基础项 + 79 × 每级成长项
```

本表 60 个角色的基础暴击率均为 **5%**，基础暴击伤害均为 **50%**。代码中的对应比例值为 `0.05` 和 `0.5`。
