# 货币战争角色数值

适用于4.7正式版的货币战争 S2。覆盖 61 个角色条目、63 个玩法角色 ID 和 216 个角色星级配置。常规账号角色的等级成长见[角色 ID 与 80 级基础数值](character-data.md)。

## 字段口径

- 角色按图鉴页顺序排列，每个星级占一行。角色名只在角色首行显示，玩法 ID、费用和站位只在该玩法形态的首行显示。`—` 表示该字段缺省。
- 前台、后台、治疗和护盾强度为配置中的基础值。生命和速度列为增幅，按百分比展示。
- 初始能量列为通用初始能量。后台能量按「初始/上限」列出，60/120 表示初始 60、上限 120，—/90 表示常规初始能量未指定、上限为 90。专属能量条按角色技能规则充能。
- 各角色星级的基础幸运率均为 5%，基础幸运伤害均为 100%。
- 基础修正和星魂修正计入同一伤害增幅。星魂修正列给出每增加一魂时增加的数值。
