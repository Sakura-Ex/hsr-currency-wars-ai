# 光锥 ID 与 80 级基础数值

收录 172 件光锥，按命途分组。章节标题括号内为命途键。角色范围与对应 ID 见[角色 ID 与 80 级基础数值](character-data.md)。

## 字段与计算口径

- **光锥 ID**：账号配置使用的条目 ID，以字符串传递；同一光锥的不同装备实例另设实例 ID。
- **稀有度**：光锥的三／四／五星稀有度。
- **生命、攻击、防御**：光锥 80 级、突破阶段 6 的基础数值，保留小数精度。
- **叠影**：通过光锥效果参数计算，基础生命、攻击、防御由等级和突破阶段确定。

```text
80 级基础值 = 突破阶段 6 的基础项 + 79 × 每级成长项
```

游戏内数值对照待完成。具体装备限制由账号资源和局内规则处理。

## 编号分类与持有数量

账号生成按下表维护光锥种类的实例数量约束。

| ID 分类 | 光锥类别 | 收录范围 | 同 ID 的持有约束 |
| --- | --- | --- | --- |
| `20xxx`、`21xxx`、`23xxx` | 其他三星、四星、五星光锥 | 见各命途列表 | 允许多个实例 |
| `22xxx` | 活动光锥 | `22000`～`22009`，共 10 件 | 至多一个实例 |
| `24xxx` | 模拟宇宙光锥 | `24000`～`24006`，共 7 件 | 至多一个实例 |

活动光锥和模拟宇宙光锥的叠影等级记录在唯一实例上，取值 1～5。其他光锥的多个实例使用不同实例 ID，各自保存等级与叠影，并分别分配装备归属。账号资源的组装方式见[光锥持有与装备实例](../modules/account-generation/design.md#光锥持有与装备实例)。
