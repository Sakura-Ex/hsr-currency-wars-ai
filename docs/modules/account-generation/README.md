# 账号与遗器数据

账号级金数与统一五星配装、推荐队友关联、资源集中分配及角色和遗器生成已实现。玩家数据接入与实际配置转换处于设计阶段。

账号生成器属于研究与训练工具，代码位于 `research/account_generation/`，按 `relics/`、`characters/`、`accounts/` 三组组织，对外通过 `research.account_generation` 导入。调用方传入参数和随机源，取得生成结果，再交给账号组装与配置转换。

| 阅读入口 | 主要内容 |
| --- | --- |
| [账号数据生成](account-generation.md) | 精确金数、全 01／全 21、候选范围、投入分布和统一装备库存 |
| [完整角色配置生成](character-generation.md) | 角色练度、推荐配装、光锥、六件遗器实例与装备引用，以及 IDE 示例 |
| [角色 ID 与 80 级基础数值](../../game-data/character-data.md) | 货币战争角色名单、命途和基础数值 |
| [光锥 ID 与 80 级基础数值](../../game-data/light-cone-data.md) | 按命途分类的光锥 ID、名称、稀有度和基础数值 |
| [五星遗器数据](../../game-data/relic-data.md) | +15 主词条、副词条档位、部位与属性键、套装 ID 对照 |
| [遗器练度五档设计](relic-quality.md) | 按推荐属性种数和合法得分上限划分低练至毕业五档 |

| [账号数据流与模块职责](data-flow.md) | 生成、玩家数据接入和试用配置如何汇合，以及模型与战斗侧如何共用转换结果 |
| [数据设计与首个样例](design.md) | 原始字段、推荐搭配与权重、光锥实例限制、账号资源指标和样例交付条件 |
| [系统设计](../../project/architecture.md) | 模块调用方式、状态归属和研究训练安排 |

生成账号时，从账号接口页开始；生成完整角色时查角色配置接口页；验证单件生成时查对应接口页。扩展账号生成或对接下游时，先阅读数据流，再查数据设计。
