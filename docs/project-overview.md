# 项目目标与使用方式

状态：讨论稿。日期：2026-11-05。

## 项目目标

开发一款面向 Windows 玩家的开源货币战争策略工具。通过模拟、搜索和学习寻找阵容与运营策略，结合玩家的账号资源和当前局面，为整局游戏提供决策建议。

工具的优化目标是在给定时间内提高最高难度下的整局通关概率，帮助玩家保持长期局外连胜。伤害、血量、金币、晶矿、局内连胜和阵容新颖性用于解释局面、筛选策略和辅助训练，最终效果以整局通关结果评估。

策略需要考虑账号资源、当前可见信息、随机发牌、节点进度和操作时间。通用研究可探索各种合法配置；给玩家的建议应符合该账号实际可用的资源及合法试用配置。

## 玩家使用流程

1. 在本地录入或导入账号资源和当前局面。
2. 查看推荐操作、候选方案、推荐理由和预期收益。
3. 执行操作并记录结果，供研究端校准规则和评估策略。

玩家端计划在本地离线运行，使用 CPU 推理，并提供 Windows 安装包。它负责规则计算、轻量模型推理，以及在给定时间内搜索当前局面的可选方案。最低配置和响应时间通过原型实测确定，测试时同时运行游戏。

接入账号数据时，先将外部数据转换为统一的账号资源格式，再用于策略决策。具体格式和工具适配方案在开发账号模块时，根据实际样本确定。

## 研究设备

研究端负责批量模拟、搜索和模型训练。开发主机配置为 i9-14900K、RTX 4090、96 GB 内存，约有 3 TB 可用磁盘。
