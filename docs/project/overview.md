# 项目目标与使用方式

状态：讨论稿。日期：2026-11-10。账号生成、模拟和模型训练均待实现。

## 项目目标

本项目计划开发一款面向 Windows 玩家的开源货币战争策略工具。工具根据玩家的账号资源和当前局面，比较阵容、战斗操作和运营方案，为一整局游戏提供决策建议。玩家查看建议后，在游戏中执行操作。

核心目标是在给定时间内，提高最高难度下的整局通关概率，并帮助玩家连续多局通关（局外连胜）。这里的时间指玩家完成一整局游戏所花的总时间，包括操作和重试。具体时间预算和通关判定，在选定验收场景时明确。

生成建议时，工具需要考虑账号可用资源、当时可见的信息、随机发牌、节点进度和操作时间。研究阶段可以探索各种合法配置；面向玩家的建议应符合该账号实际可用的资源及合法试用配置。

普通对局以整局通关结果评估。研究还将训练模型适应不同账号，并熟练运用多种阵容及运营路线；各类打法分别报告效果。

挑战任务可以组合全试用、SSS、不重开和连续多局使用不同打法等条件。当前讨论的目标为连续 20 局、全试用、每局最终血量至少 100，且打法不同。SSS 在该挑战中按最终血量 ≥100 判断，当前血量与血量上限分别记录。最高伤害角色不同，或决定性因素不同，都可以作为打法差异的依据。具体伤害统计范围、决定性因素的判定、整局重开与战斗重试的限制，在挑战开始前固定。挑战效果以整套任务完成率评估。

伤害、血量、金币、晶矿和局内连胜用于分析局面及辅助训练；训练奖励与当前任务的成功条件对应。

模块职责和候选技术见[系统设计与技术方案](architecture.md)，各阶段的工作和验收条件见[实施阶段与任务拆解](roadmap.md)。

## 玩家使用流程

计划中的使用流程如下：

1. 在本地录入或导入账号资源和当前局面。
2. 查看推荐操作、其他候选方案、推荐理由和预期收益。
3. 在游戏中执行操作并记录结果，用于后续校准规则和评估策略。

玩家端计划提供 Windows 安装包，在本地离线运行，使用 CPU 完成规则计算、轻量模型推理和限定时间内的方案搜索。最低硬件配置和响应时间通过原型实测确定，测试时同时运行游戏。

账号导出首轮接入 [reliquary-archiver](https://github.com/IceDynamix/reliquary-archiver) 的 JSON，根据实际样本核对字段和角色标识。账号导出、程序生成和试用数据经过统一转换，按货币战争规则得到实际生效配置，再分别生成模型输入和战斗模拟输入。配置表示、账号生成与评价方法见[账号与遗器数据](../modules/account-generation/design.md)。

## 研究设备

研究端负责批量模拟、搜索和模型训练，为玩家端提供可用的策略和模型。

开发主机配置为 i9-14900K、RTX 4090、96 GB 内存，约有 3 TB 可用磁盘。
