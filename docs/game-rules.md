# 游戏规则

状态：讨论稿。日期：2026-11-10。

下表中的规则均待实测确认。实现每条规则时，记录游戏版本、样本来源和验证状态。新赛季按实际版本更新规则，并注明节点数量和机制数值适用的版本。

| 主题 | 当前规则描述 | 实现要求 |
| --- | --- | --- |
| 整局结构 | 三个位面；当前记录的赛季通常包含 20 个节点：奖励 5、战斗 9、遭遇 3、首领 3 | 在规则数据中列出节点及其顺序 |
| 整局结算 | 最终结算血量大于 0 视为整局胜利；部分节点失败后仍可继续 | 分别记录节点结果与整局结果 |
| 账号配置映射 | 游戏会将练度不足的配置映射到默认配置，包括等级 80 和行迹等级保底 | 逐项核对触发条件、替换字段和默认值；转换模块按版本执行，向模型和战斗模拟提供同一份生效配置 |
| 试用配置 | 未持有角色可按游戏允许的条件使用试用配置，其实际配置可能低于本体 | 记录试用来源及实际配置，核对试用范围、装备限制和生效规则 |
| 整局血量 | 战斗失败可能扣除整局血量，部分机制可能提高血量上限 | 分别记录当前血量、血量上限及结算变化，核对扣血、回血和加上限的时机；挑战成功条件由任务另行指定 |
| 经济 | 金币利息、局内连胜影响收入；利息通常上限为 5；奖励节点保持连胜计数 | 按节点类型结算资源 |
| 可见信息 | 开局可观察首领、可能的小怪及负面词条；后续角色牌随流程揭示 | 用当时可见的信息作为策略输入 |
| 奖励节点 | 普通奖励关与特殊扑满关各有规则；扑满逃离可判节点胜利，击杀提供晶矿 | 分别记录胜负、击杀及资源收益 |
| 战斗重试 | 同一次进入中的相同操作可复现；改变操作可能改变结果；重新进入可能改变随机结果 | 分别记录操作序列和重新进入时的随机采样 |
| 暂离调整 | 暂离后可调整站位，阵容和装备沿用该场配置 | 根据战斗阶段列出可执行的操作 |
| 重试时机 | 重试发生于战斗结算前 | 在结算前决定是否重试 |
| 战斗控制 | 自动、局部手动干预及完整手动的收益和耗时随阵容变化 | 比较通关收益与操作、计算、重试所需的时间 |
