# HSR Currency Wars AI

[English](README.md) | 简体中文

面向 Windows 玩家的开源 AI 策略研究与辅助项目，用于《崩坏：星穹铁道》的货币战争玩法。

## 项目目标

- 探索并评估阵容、战斗决策和运营策略。
- 根据玩家可用的角色与装备提供适合该账号的策略建议。
- 将研究、训练任务与日常使用的轻量本地推理分开。
- 提供标准化的账号数据导入接口，具体接入方式将在后续开发中确定。

## 当前状态

仓库目前处于初始化阶段。应用、模拟器和训练模型待实现；架构、实现语言和硬件要求待验证。

项目计划、开发约定和模块设计见[文档入口](docs/README.md)，这些资料使用中文。

面向公众的项目介绍、玩家指南和发布说明提供英语与简体中文两个版本，并同步维护。设计文档、开发约定和项目协作使用中文。代码标识符、路径及工具固定字段保留原名。
