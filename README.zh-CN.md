# HSR Currency Wars AI

[English](README.md) | 简体中文

面向 Windows 玩家的开源 AI 策略研究与辅助项目，用于《崩坏：星穹铁道》的货币战争玩法。

## 项目目标

- 探索并评估阵容、战斗决策和运营策略。
- 根据玩家可用的角色与装备提供适合该账号的策略建议。

## 当前状态

项目处于早期开发阶段，Windows 玩家应用尚未发布。

项目计划、设计和开发指南见[文档入口](docs/README.md)，这些资料使用中文。
